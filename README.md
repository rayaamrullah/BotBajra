# What Is This?

This is a Extraordinary Generation's Whatsapp bot run on node.

# Why do you make it?

Because I wanna make some important links accessible easily through whatsapp.

## Installation

Install dependencies on package.json.

## Usage

1. Run index.js via node on your server or localhost
2. Scan the qr code shown on screen with your Whatsapp App
3. Send command to the bot
